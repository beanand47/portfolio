# Portfolio

This is a static portfolio site built with HTML and CSS.

## Deploy
To publish this site on GitHub Pages:

1. Create a new GitHub repository.
2. Add this folder as a git repository.
3. Push to GitHub.
4. Enable GitHub Pages on the repo (use the `main` branch and `/root`).

## Files
- `index.html`
- `work.html`
- `watch.html`
- `read.html`
- `newsletters.html`
- `style.css`
